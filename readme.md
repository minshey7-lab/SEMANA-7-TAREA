# Calculo para el Area de 3 figuras

Aplicación de consola en Java que calcula el área de diferentes figuras usando la programación Orientada a Objetos: Abstracción, Encapsulamiento, Herencia, Sobrescritura y Polimorfismo. 
El proyecto define una clase abstracta utlizando **FIGURA**. el programa recorre un arreglo de figuras y calcula sus áreas dinámicamente.

## Figuras Implementadas
- Círculo
- Rectángulo
- Triángulo

## Instrucciones de Ejecución

1. Abrir el proyecto en IntelliJ IDEA 
2. Asegurarse de tener configurado el JDK de Java.
3. Navegar hasta la clase `src/Main.java`. Ahi puede validar lo valores que le quieras ingresar a las figuras para calcularle el Areas 
4. Ejecutar la clase `Main` desde el boton de ejefcucion de la parte superior
